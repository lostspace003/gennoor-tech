### 🔧 **How Each Feature Works:**

#### **1. Excel Upload (Admin Only)**
```
1. Click "Upload Excel" button (green button in top bar)
2. Select .xlsx file with leads
3. System auto-maps columns (flexible schema)
4. Missing fields filled with "NA"
5. Progress bar shows upload status
6. Leads added to database
```

#### **2. AI Research**
```
1. Select leads using checkboxes
2. Click "AI Research" button
3. System fetches:
   - Company information
   - LinkedIn data
   - Tech stack analysis
   - Pain points & opportunities
4. Research saved to lead profile
```

#### **3. Email Automation**
```
1. Select target leads
2. Click "Email Selected"
3. AI generates personalized draft
4. Review/edit draft
5. Click "Send Email"
6. Auto CC to admin@gennoor.com
```

#### **4. GennoorBot Usage**
```
1. Click chat icon (bottom right)
2. Bot slides from right
3. Type commands like:
   - "Research ABC company"
   - "Draft email for leads"
   - "Show high priority leads"
4. Bot executes via CRM API
```
