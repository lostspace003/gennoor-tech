# POC videos we can record from the admin centre

This is a list to choose from. Nothing has been built or recorded yet.

**The count: 12 separate POCs.** Each one is a real, working part of the admin centre or the CRM, so each
video shows something that exists, not a mock-up.

## How each video would be made (the same for all)

- **Voice:** your own voice, from the Course Factory voice project, on this machine.
- **Shape:** a few slides (the problem, what the system does, the result), then the real screen being used,
  then one closing slide.
- **Sensitive content:** names, email addresses, phone numbers, amounts and keys are blurred or replaced with
  made-up people. The screens, the buttons and the flow stay visible, so the viewer sees how it works.
- **Length:** about 2 to 4 minutes each.
- **Not shown in any of them:** prices, customer names, the name of a trainer.

## What I need from you before making any

1. **Which of the 12** you want, and in what order.
2. **Who they are for**: a client being shown what we can build for them, or people on LinkedIn. That decides
   how much is explained.
3. **Wide (16:9), tall (9:16 for Reels), or both.**
4. For the ones that send something (2, 4, 6, 8, 9): they will be recorded with made-up people and a pretend
   server, so **no real email or post goes out** during recording. Say if you want it otherwise.
