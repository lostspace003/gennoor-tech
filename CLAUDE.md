# Gennoor Tech website

The rules for working here are in AGENTS.md, so that every tool reads the same ones:

@AGENTS.md

Before changing anything a person sees, use the skill `gennoor-site-design`. For films, the presentation
or social videos, `gennoor-films`. To finish a piece of work, `gennoor-ship`.

Before adding or changing anything that takes words, a file name, an address or HTML from a visitor, from the
browser or from a model (a form, an address under `src/app/api`, sign-in, the chatbot, the blog studio, the
CRM's documents, a file in `public/`), use the skill `gennoor-security`. That is most changes: when in doubt,
use it.
